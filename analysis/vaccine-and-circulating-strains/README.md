# Vaccine vs. circulating-strains analysis

This folder is a **worked, dataset-specific example** of post-processing the outputs of the
[`rvfvphylo`](../../README.md) pipeline. It is *not* part of the pipeline itself — nothing
here is invoked by `main.nf` — it's the downstream R/Python analysis used to turn per-segment
`rvfvcirculatingstrains` runs into the figures and manuscript tables for the RVFV
vaccine-vs-circulating-strains comparison.

It expects a specific directory layout that isn't included in this repository (the pipeline
outputs are large, per-dataset, and regenerated by re-running `rvfvphylo`):

```text
vaccine-and-circulating-strains/         <- this directory (open as the RStudio project root)
├── vaccine-and-circulating-strains.Rproj
├── scripts/                             <- everything in this repo
└── segments/                            <- NOT included; created by running rvfvphylo per segment
    ├── L/complete/global/
    │   ├── assignment/output-dir/report/lineages.csv
    │   └── output-dir/riftL/...         <- from `--subworkflow rvfvcirculatingstrains --segment L --prefix riftL`
    ├── M/complete/global/
    │   └── output-dir/riftM/...         <- --segment M --prefix riftM
    └── S/complete/global/
        ├── output-dir/riftS-NP/...      <- --segment S-NP  --prefix riftS-NP
        └── output-dir/riftS-NSS/...     <- --segment S-NSS --prefix riftS-NSS
```

Run `rvfvphylo` once per segment (see the [main README](../../README.md#usage) for the
`nextflow run` command), pointing `--outdir` at `segments/<segment>/complete/global/output-dir`
with the matching `--prefix rift<Segment>`, before running any script below.

## Scripts

| Script | Purpose |
| --- | --- |
| `prepareMetadataRVFV.R` | Builds/normalizes the combined sample metadata used by the figure scripts. |
| `Fig1.R` – `Fig5.R`, `Fig2_extended.R` | Figures 1–5 (root-to-tip regressions, strain-type/lineage summaries, etc.) for the manuscript. Current versions — supersede an earlier `Figure1.R`–`Figure4.R` draft series not included here. |
| `TangleTrees.R` | Tanglegram comparison of per-segment phylogenies. |
| `plot_mutations_heatmaps.R` | Heatmap of per-strain mutation frequencies for a segment. |
| `plots.R` | Older/general plotting helper functions shared by earlier figure drafts. |
| `analyze_vaccine_substitutions_multisegment.R` | Core analysis: classifies vaccine-strain substitutions across segments and writes the per-vaccine/per-segment CSVs consumed by `build_tables.R`. |
| `build_tables.R` | Builds the main-text table and supplementary workbook from the CSVs produced by `analyze_vaccine_substitutions_multisegment.R`. Note: its header comments still refer to an older filename (`..._v3.R`) for that script — same script, just renamed since. |
| `extract_hyphy_ci_from_json.py` | Extracts a HyPhy FEL/FUBAR confidence interval for a given codon site from its JSON output. Generic CLI tool (`--json --site`), reusable outside this dataset. |
| `addStrainsTypes.py` | Assigns strain types to an alignment from lineage/metadata input. Generic CLI tool (`--alignment --lineage --metadata --prefix`), reusable outside this dataset. |
| `utils.R` / `utils.py` | Shared helper functions sourced/imported by the scripts above. |

## Running

The R scripts use relative sourcing (`source("scripts/utils.R")`) and `rprojroot` to locate
the project root, so run them **from this directory** (`vaccine-and-circulating-strains/`),
not from inside `scripts/`:

```bash
cd analysis/vaccine-and-circulating-strains
Rscript scripts/Fig1.R
```

Opening `vaccine-and-circulating-strains.Rproj` in RStudio and running from there works the
same way.

The two Python CLI scripts can be run directly, e.g.:

```bash
python3 scripts/extract_hyphy_ci_from_json.py \
    --json segments/M/complete/global/output-dir/riftM/hyphy/riftM.FUBAR.json \
    --site 278
```

## Dependencies

Not covered by the pipeline's own `environment.yml` (these are analysis-time, not
pipeline-run-time, dependencies):

- **R**: `tidyverse`, `ape`, `phytools`, `treeio`, `ggtree`, `ggtreeExtra`, `ggnewscale`,
  `ggrepel`, `ggridges`, `ggthemes`, `ggtext`, `ggh4x`, `ggimage`, `rphylopic`, `scatterpie`,
  `patchwork`, `cowplot`, `lemon`, `paletteer`, `colorspace`, `RColorBrewer`, `hrbrthemes`,
  `showtext`, `extrafont`, `sf`, `sp`, `maps`, `dendextend`, `countrycode`, `tidytext`, `gt`,
  `openxlsx`, `pheatmap`, `glue`, `jsonlite`, `rprojroot`, `rstudioapi`
- **Python**: `pandas`, `numpy`, `pycountry`

These are personal analysis tools, not pinned/tested as a pipeline dependency set — install
what each script's `library()`/`import` calls need for your R/Python environment.
